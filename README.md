# الحاسبة الاستثمارية الشاملة

تطبيق ويب قابل للتثبيت (PWA): ملف واحد يعمل بلا إنترنت، وتبقى بياناتك في جهازك.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (مثلًا `investment-calculator`).
2. ارفع كل ملفات هذا المجلد إلى جذر المستودع (Add file ← Upload files).
3. من Settings ← Pages: اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`، واحفظ.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/investment-calculator/`

## التثبيت على الجوال
افتح الرابط في Chrome أو Safari ← القائمة ← «إضافة إلى الشاشة الرئيسية» / «تثبيت التطبيق».

## التحديث
عدّل `index.html` وارفعه، ثم غيّر رقم `V` في `sw.js` (مثل `invcalc-v2`) ليحصل المستخدمون على النسخة الجديدة.

## ملاحظة
البيانات تُحفظ في متصفح كل جهاز. استخدم «تصدير نسخة احتياطية» من صفحة المشاريع لنقلها بين الأجهزة.
